# workout-tracker

A static workout tracker for GitHub Pages. Single file, no build step, no accounts.

## Features

- Daily workout with weight and reps per set, last-time hints and personal record alerts
- Daily checklist you can edit
- Monthly calendar with an auto-built plan based on your equipment and training days
- Fresh exercises each month, with a shuffle button per workout
- Stats tab: totals, records, weekly volume, muscle split, exercise progress, activity map, month by month, milestones
- Weekly grocery list
- Backup and restore as JSON, export sets as CSV

All data is saved only in your browser. General fitness information, not medical advice.

## Deploy

1. Push `index.html` to a GitHub repo named `workout-tracker`
2. Settings, Pages, deploy from branch `main`, folder `/ (root)`
3. Open `https://YOURNAME.github.io/workout-tracker/`
